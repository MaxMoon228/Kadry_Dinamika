## Реальная выгрузка (локальный режим) — отличия от описания

Подтверждено на файлах `Педагоги.xlsx`, `Образование.xlsx`, `ПК-ПП.xlsx`, `Школы.xlsx` (листы 2022, 2023, 2024):

| Описание источника | Реальная выгрузка | Как обработано |
|---|---|---|
| Краткое наименование ОО | `ID образовательной организации` (число) | `school_id = sch-<номер>`, название «Школа № <номер>» |
| (Год среза) | лист Excel `2022/2023/2024` | колонка `year` |
| Преподаёт в предпроф. классах | **нет** | разрезы скрываются (`meta.unavailableFields`) |
| Организатор программы ПК/ПП | **нет** | колонка в профиле скрывается |
| Даты категории / окончания / документа | только год | `YYYY-01-01`, в UI показывается год |
| «Школы» по годам | одна таблица (266 школ) | одинаковые здания и контингент во всех годах |
| «Учителя» | 428 140 строк; 10 991 строка со школой вне справочника | в итоговую таблицу не входят (как в ноутбуке) |

## Итоговая таблица df_final (ноутбук «Неделя 4_ДЗ_Рачайочечки»)

Одна строка — педагог × год, 52 723 строки, 30 признаков. Тип `TeacherYearFeatures` (`src/domain/features.ts`), показывается в профиле педагога. Собирается скриптом `scripts/real-data/build_real_dataset.py`, который повторяет ноутбук шаг за шагом.

| Признак | Правило (как в ноутбуке) |
|---|---|
| `main_position_cat` | ключевые слова должности → учитель / руководитель / другой |
| `academic_degree_cat`, `category_qual_cat` | поиск «доктор/кандидат», «высшая/первая/вторая» |
| `category_active` | срок действия > года среза → «активно»; нет срока → «не было» |
| `experience_age_other` | общий стаж − педагогический |
| `n_unique_subjects` | число разных предметов педагога в году (после чистки текста) |
| `min_parallel`, `max_parallel`, `n_unique_parallel` | по строкам «предмет × параллель» |
| `class_manager` | max по строкам педагога |
| `is_exam_subject` | в названии предмета «егэ / огэ / гиа» |
| `main_subject_group` | самая частая из 8 групп предметов |
| `district`, `buildings_num`, `students_num` | из «Школы» |
| `is_ped_education` | «педагог / учител / преподава / методик» в специализации, квалификации или вузе |
| `high_type_education` | высший уровень: аспирантура > высшее > СПО > школа |
| `n_courses`, `hours_courses`, `n_gia_courses`, `has_pp` | ПК/ПП за год |
| `target` | 0 — остался, 1 — ушёл, 2 — перевёлся; NaN для 2024 |

**Кодировка target.** В ноутбуке 1 — «ушёл», 2 — «перевёлся». На сайте (Приложение 1) 1 — «перешёл», 2 — «ушёл». Скрипт хранит оба значения: `target` (как в ноутбуке) и `status` (для сайта). Присутствие в t+1 определяется по исходным листам до фильтрации школ, поэтому переход в школу вне справочника считается переходом, а не уходом.

## Нагрузка: что есть в данных

Часов и ставок в выгрузке нет. Есть **число разных предметов** (`n_unique_subjects`, в ноутбуке «Неделя 5» — «Количество уроков») и число параллелей. Это косвенная мера разноплановой нагрузки, не нагрузка в часах.

**Критическая нагрузка** (ноутбук «Неделя 5_НС_Учителя_Семинар»): `experience_age_pedagogic < 2` и `n_unique_subjects ≥ 5` (`CRITICAL_LOAD` в `src/domain/features.ts`). Используется в графике «Нагрузка молодых педагогов» на Обзоре и в профиле педагога. Это описательный индикатор, не причина ухода.

## Поля, которых в источнике нет

Заработная плата, учебная нагрузка в часах, ставки, удовлетворённость, вовлечённость, выгорание, причины ухода, KPI, дата найма в текущую школу, стаж в текущей школе, полная карьерная история, муниципалитет или район (есть только округ). Такие показатели не используются в UI и ML. «Стаж в текущей школе» можно оценить только цензурированно, по числу подряд идущих срезов в той же школе (максимум 3), с явной пометкой «в пределах окна наблюдения».
